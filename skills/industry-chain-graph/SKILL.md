# 产业链图谱与概况生成 Skill

输入"【地区(可省)】+【产业链名称】+产业链"，产出《{产业链名称}产业链.xlsx》，包含 **概况**、**图谱** 两个数据 sheet（另预留"上链策略""挂链策略"空 sheet，由后续版本填充）。

标准示例：`references/示例-生猪产业链.xlsx`（武汉+生猪的产出样例），生成任何内容前必须先读它对齐格式与颗粒度。

## 输入与输出

- 触发：用户输入须包含"产业链"三字，固定格式"【地区】+【产业链名称】+产业链"（如"武汉市生猪产业链""武汉生猪产业链"）。不含"产业链"的请求不调用本 skill。
- 解析：去掉末尾"产业链"后，剩余开头为行政区划（省/市/区县，如"武汉""武汉市""湖北省"）的作为地区，其余为产业链名称。**无地区时不追问，直接按全国范围调研**（如"生猪产业链"→产业链名称=生猪，全国调研）。
- 输出文件：当前工作目录下 `{产业链名称}产业链.xlsx`（如"生猪产业链.xlsx"）。skill 随目录整体分发到其他 agent 平台时，路径一律使用相对路径。
- 产业链编号（chain_code）：取产业链名称各汉字拼音首字母小写（如 生猪→sz、低空经济→dkjj）；名称含英文单词则取英文首字母。若编号与既有产业链冲突，可自行调整并向用户说明。
- 若输出文件已存在，先向用户确认是否覆盖。
- 交付：完成后必须把 xlsx 文件直接发送到对话框（详见"交付方式"），不允许只写盘不交付。

## 执行流程

### Step 1 调研产业政策

有地区则"地区+全国"两层调研，无地区则仅全国调研。用 WebSearch 调研并沉淀"政策要点清单"（在对话中简要输出），查询建议：

- 有地区：`{地区} {产业链名称} 产业政策`、`{地区} 十五五 {产业链名称}`、`{地区} {产业链名称} 产业集群/重点园区`
- 全国：`{产业链名称} 国家十五五规划`、`全国 {产业链名称} 重点区域 布局`、`全国 {产业链名称} 产业政策`
- `全国 {产业链名称} 企业数量`（用于全国企业量级）

清单需覆盖：（有地区时）当地产业定位与政策方向、重点园区/集群/项目，以及全国重点布局区域（用于产业链标签）、全国企业量级线索。调研结果用于 Step 2 的赛道取舍与 Step 5 的描述/标签。

### Step 2 绘制产业图谱

结合 Step 1 调研所得政策（有地区=当地+全国，无地区=全国）与最新国家产业规划（如十五五），设计树形图谱。硬性规则：

1. **层级**：4~8 级，按产业规模定（一般 4~5 级，细分赛道多的可到 6~8 级）。同级分支建议 3~6 个。
2. **一级节点尽可能 3 个**，分别对应上游、中游、下游，但**节点名称必须是具体赛道名称**（如"种源与投入品""生猪养殖与屠宰"），**严禁出现"上游/中游/下游"字样的节点**。设备、辅料等支撑环节归入其所服务环节所在的分支（示例中养殖设备归上游）。
3. **拼接禁令**：不同节点、不同产品禁止用"/""、"等拼在同一行，必须各占一行；仅"同一含义不同叫法"允许在单个节点名称内用"/"（如"冷库/冷藏库"）。
4. 节点名称用行业通用赛道/产品名，简洁准确（≤12字为宜）；叶子层为具体产品、设备或服务形态。
5. 政策重点方向应落位：体现为核心节点或新设赛道（如智能装备、绿色低碳、预制菜等）。
6. 中游=核心产品的生产/制造环节；下游=加工、流通、销售、服务环节。

先在对话中以缩进文本输出完整图谱树供用户确认，再进入 Step 3。

### Step 3 节点编号

- 一级：`{chain_code}01、{chain_code}02、…`（两位递增，01 起，不跳号）。
- N 级：父编号 + 两位递增。如 sz → sz01 → sz0101 → sz010101 → sz01010101。
- 同一父节点下按业务顺序编号；上游分支=01 起的中游、下游分支依次排后。

### Step 4 结构化"图谱" sheet

列数 = 最大层级×2 + 7。以 4 级为例共 15 列（A:O）：

| 列 | 中文表头 | 英文字段 |
|---|---|---|
| A/B | 一级节点编号 / 一级节点名称 | node_code1 / node_name1 |
| C/D… | 二级…第N级 节点编号/名称 | node_code2…node_codeN / node_name2…node_nameN |
| 倒数第7/6 | 节点编号 / 节点名称 | node_code / node_name |
| 倒数第5/4 | 上级节点编号 / 上级节点名称 | up_node_code / up_node_name |
| 倒数第3 | 节点层级 | node_level |
| 倒数第2 | 节点所属环节 | node_link |
| 倒数第1 | 是否核心节点 | is_core_link |

填写规则：

- 第1行中文表头，第2行英文字段，第3行起数据，**每个节点一行**；产业链根节点（如"生猪"）不占数据行。
- 层级 L 的节点行：层级编号/名称列**仅在第 L 级的列对填值**，其余层级列一律留空（祖先列不做向下填充）；**7 个固定字段（节点编号/名称、上级节点编号/名称、节点层级、节点所属环节、是否核心节点）每行都必须有值**，且"节点编号/名称"与第 L 级列内容一致。
- 一级节点的上级=产业链根（up_node_code=chain_code，up_node_name=产业链名称）。
- 行序=先序遍历：父行先于子行、子树行紧随父行、兄弟按编号升序（严格对照示例）。
- node_link：第1个一级节点及其所有后代=1（上游），第2个=2（中游），第3个=3（下游）。
- is_core_link：Y=核心节点（该产业的核心、重点、新兴节点：附加值高、政策重点、对地区带动强，如示例中养殖/屠宰/繁育），N=非核心；全列只能填 Y 或 N。**核心性沿子树传导：父节点为核心节点时，其子节点原则上均应为核心节点；严禁出现"父为核心、子却全为非核心"的断层**（分支整体非重点时，应从父级起整体标 N）。

### Step 5 生成"概况" sheet

10 列（A:J），第1行中文表头、第2行英文字段、第3行数据：

| 列 | 中文表头 | 英文字段 | 填写规则 |
|---|---|---|---|
| A | 产业链编号 | chain_code | 同上 |
| B | 产业链名称 | chain_name | 如"生猪"，不带"产业链"三字 |
| C | 产业链标签 | chain_label | 全国重点发展该产业的省/市，多个用"；"拼接（如"武汉；河南；湖南；山东"） |
| D | 结构类型 | chain_type | 固定填 1（上中下游结构） |
| E | 产业链描述 | chain_info | 250~400字一段式：总体定位→上游→中游→下游→一体化/升级趋势；覆盖图谱主干，融入政策方向（有地区=当地+国家政策，无地区=全国政策与布局）（描述文字中可以用"上游/中游/下游"表述）。**描述中严禁体现地区信息：不得出现任何地区字样（如"武汉""湖北"等），配置的地区仅作为调研重点与图谱生成偏向（赛道取舍、核心节点判断），描述一律按全国视角表述** |
| F | 产业分类 | chain_class_one | 从 `产业分类与领域.xlsx`"产业分类"sheet 的产业分类列中选一（战新产业/未来产业/传统产业/特色产业），依据其"产业链"清单就近匹配 |
| G | 产业领域 | chain_class_two | 从"产业领域"sheet 的产业领域列中选一，依据其"产业链"清单就近匹配 |
| H | 国标行业 | chain_ind_gb | 从 `国标行业.xlsx` Sheet1 选最相关"行业码值"（如 A0313），多个用"\|"拼接。**只选与当前产业链中游或核心环节直接对应的行业码值，准入从严：严禁把仅上游配套、仅下游流通或泛相关的行业都纳入** |
| I | 申万行业 | chain_ind_sw | 从 `申万行业.xlsx` Sheet2 选最相关三级代码（如 110702），多个用"\|"拼接。**只选与当前产业链中游或核心环节直接对应的行业代码，准入从严：严禁把仅上游配套、仅下游流通或泛相关的行业都纳入** |
| J | 全国企业量级 | chain_ent_scale | 数值，单位"万"，仅企业不含个体工商户；优先用调研数据，无则给出合理估计（示例：生猪=30） |

## Excel 写入（按运行环境选择方式，优先级 A > B > C）

**方式 A —— 有 Excel/电子表格类工具（如 mcp_Excel）**，按步骤 1~6 执行：

1. 复制模板：将 skill 目录下 `references/模板-空表.xlsx` 复制为输出文件（PowerShell：`Copy-Item "references/模板-空表.xlsx" "{产业链名称}产业链.xlsx"`；bash：`cp references/模板-空表.xlsx {产业链名称}产业链.xlsx`；均相对 skill 目录执行）。
2. 写"概况"：`excel_write_to_sheet`，sheetName=概况，newSheet=false，range=A1:J3，values 为 3 行×10 列二维数组（数字如 1、30 写数值，编号/码值写字符串）。
3. 写"图谱"表头：range=A1:{末列}2（2 行）。若层级>4，动态列按 `{N}级节点编号/{N}级节点名称` 顺延。
4. 写"图谱"数据（构造时即定形，不靠事后清理）：每个节点组装为一行完整数组后再写，**每个单元格必须显式给值或显式 null，禁止留空、省略或沿用上一行**：
   - 第 L 级节点行：仅第 (L-1)×2+1、(L-1)×2+2 列填该节点编号/名称，**其余所有层级列一律写 null**（以 4 级为例：一级行 C:H=null；二级行 A:B、E:H=null；三级行 A:D、G:H=null；四级行 A:F=null）。
   - 固定 7 列逐格给值：节点编号/名称=第 L 级列同值；上级节点编号/名称（一级=chain_code/产业链名称，其余=父节点）；节点层级=L；节点所属环节=1/2/3；是否核心节点=Y/N。
   - range=A3:{末列}{2+节点数}；数据量大时分多次写（每次≤40行），每次仍按完整行数组传值。
5. 加粗表头：`excel_format_range`，概况 A1:J2、图谱 A1:{末列}2，font bold size 10。
6. 校验：`excel_describe_sheets` 确认 4 个 sheet 与 usedRange；`excel_read_sheet` 抽读首、中、尾各几行，重点核对：任一行除自身层级列对外，其余层级列均为空；节点编号与自身层级列一致。

**方式 B —— 无 Excel 类工具、但可执行代码（如 Python）**：用 openpyxl 按方式 A 的相同结构完成：复制模板 → 逐 sheet 写入单元格（概况 A1:J3；图谱两行表头 + 数据行，**非自身层级列写 None，不向下填充**，表头置加粗）→ 重新打开文件抽读校验。

**方式 C —— 既无 Excel 类工具也不能执行代码**：输出"概况""图谱"两份 CSV 数据（UTF-8 编码）与模板粘贴/导入说明，交由用户完成落表；行列结构与自检清单保持不变。

## 交付方式（生成并自检通过后执行）

按运行环境选择，能同时满足的两者都做：

1. **对话框交付（所有模式必须）**：用平台原生文件输出/上传能力，把《{产业链名称}产业链.xlsx》作为文件附件直接发送到对话框（如 Kimi/豆包的文件生成与下载、工作空间的文件卡片）。同时在对话中给出：文件名、sheet 清单、图谱节点数、概况要点摘要。
2. **工作区落盘（具备文件系统/项目空间时）**：将 xlsx 保存到当前工作目录（相对路径 `{产业链名称}产业链.xlsx`），并在对话中告知已保存的相对位置。
3. **降级（平台既不能发文件附件也不能写盘）**：输出"概况""图谱"两份 CSV 数据（UTF-8 编码）+ 模板使用说明，交由用户粘贴/导入到模板对应 sheet；行列结构与自检清单保持不变。

任何模式下均不使用绝对路径。

## 自检清单（输出前逐项核对）

- [ ] 图谱列数=最大层级×2+7；概况 10 列；表头中英文两行齐全
- [ ] 每行：节点编号=该行层级路径编号；up_node/节点层级一致；层级列只填自身层级对、其余留空；父行先于子行、兄弟升序
- [ ] 一级节点=3 个且无"上游/中游/下游"字样；除同义别名外无"/""、"拼接
- [ ] node_link 与一级节点序号（1/2/3）一致；is_core_link 只有 Y/N；核心节点子树连续（无"父核心、子全非核心"断层）
- [ ] 概况：chain_type=1；标签用"；"；分类/领域与参考文件条目一字不差；国标/申万为参考文件中真实存在的码值，且仅覆盖中游或核心环节（准入从严）
- [ ] 文件名、4 个 sheet 名称与示例一致；描述为一段式 250~400 字；描述中无任何地区字样（地区仅用于调研与图谱偏向）
- [ ] xlsx 已作为文件附件发送到对话框；具备文件系统时已另存到当前工作目录（相对路径）
